# COGNICOO — Дашборд навантаження команди

## Що це?
Інтерактивний графік навантаження команди, який автоматично підтягує задачі з Notion і показує хто чим зайнятий, коли вільний, і коли планувати наступного клієнта.

**Посилання:** https://alionamakaida-cloud.github.io/cognicoo-dashboard/

## Як це працює?

```
Notion (Tasks – Наші справи) → Cloudflare Worker (проксі) → Дашборд (GitHub Pages)
```

Дані оновлюються автоматично кожні 5 хвилин. Просто оновлюй сторінку.

## Що потрібно заповнювати в Notion?

Для кожної задачі в базі "Tasks – Наші справи" важливо заповнити:

| Поле | Що писати | Приклад |
|------|-----------|---------|
| **Task name** | Назва задачі | Soft Sich — профілі команди |
| **Assignee** | Хто виконує | Альона / Таня / Андрій |
| **Status** | Поточний статус | Backlog → in process → Перевірка → Підтверджено → Done all |
| **Client** | Клієнт/проєкт | Soft Sich, Bloom Print, Cognicoo |
| **Due date** | Дата ПОЧАТКУ роботи | 01/04/2026 |
| **End Date** | Дата ЗАВЕРШЕННЯ | 15/04/2026 |
| **Priority** | Пріоритет | High / Medium / Low |

### Головне правило: ЗАВЖДИ ставте Due date + End Date!
Без дат задача не відображається правильно на графіку.

## Як вносити задачі різної тривалості?

**Коротка задача (1-7 днів):**
- "Зведений профіль клієнта Х"
- Due date: 5 квітня → End Date: 8 квітня
- Assignee: одна людина

**Середня задача (2-4 тижні):**
- "Підготовка звіту LANTEC"
- Due date: 1 квітня → End Date: 25 квітня
- Assignee: одна людина

**Довгий проєкт (2+ місяці):**
Розбийте на етапи! Замість одного таска на 6 місяців:
- "Soft Sich — діагностика" → Андрій, квітень
- "Soft Sich — профілі команди" → Альона, квітень-травень
- "Soft Sich — звіт та рекомендації" → Таня, червень

Так графік покаже реальне навантаження кожної людини.

## Що показує дашборд?

### Верхня частина
- **Карточки команди** — скільки задач у кожного, % виконання
- **Індикатори** — загальна кількість задач, скільки в роботі/на перевірці/виконано
- **Pipeline** — візуальний статус-бар всіх задач (Запит → В роботі → Перевірка → Підтверджено → Виконано)

### Таймлайн (головний графік)
- Кожен рядок = клієнт/проєкт для конкретного учасника
- Бар = тривалість роботи (від Due date до End Date)
- Червона лінія "Сьогодні" = поточна дата
- Кольори: 🔵 Андрій | 🟢 Таня | 🩷 Альона

### Деталізація місяця
- Натисніть на назву місяця у шапці таймлайну
- Відкриється міні-Gantt з тижневою розбивкою
- Бачите кожну задачу окремо з датами

### Фільтри
- Натисніть на ім'я (Андрій / Таня / Альона) щоб бачити тільки одну людину
- "Всі" — повернути всіх

### Перегляд
- **6 міс** — найближчі 6 місяців
- **Рік** — поточний рік
- **Все** — всі дані від початку

## Коли оновлювати задачі?

- **Нова задача** → одразу створити в Notion з датами та виконавцем
- **Задача розпочата** → змінити Status на "in process"
- **Задача на перевірці** → змінити Status на "Перевірка"
- **Задача підтверджена** → Status = "Підтверджено"
- **Задача виконана** → Status = "Done all"
- **Змінились терміни** → оновити Due date / End Date

Графік оновиться автоматично протягом 5 хвилин після змін в Notion.
